# 摘要提示词模板库

> 用于配置 `SUMMARY_PROMPT_TEMPLATE`。所有模板都**必须**保留 `{title}` 和 `{content}` 占位符。

## 模板 1：通用技术简报（默认风格）

```text
请为 Hacker News 的热门文章撰写微型简报。
标题: {title}
内容: {content}

请输出 Markdown 格式，包含：
1. **一句话核心**：它是什么？
2. **关键点**：3个以内的技术要点或观点。
(保持简洁，不要废话，不要使用任何表情符号)
```

## 模板 2：面向工程实践

```text
你是一名资深技术编辑，请总结以下文章。
标题：{title}
正文：{content}

请输出 Markdown，结构如下：
1. 一句话结论（20字以内）
2. 工程实践要点（最多3条）
3. 适用场景与风险提醒（最多2条）
```

## 模板 3：面向产品/管理者

```text
请将下面内容总结为适合产品经理和技术管理者阅读的简报。
标题：{title}
正文：{content}

输出 Markdown，包含：
1. 这篇文章在讲什么（1句话）
2. 对业务/团队的价值（2-3条）
3. 是否值得跟进（给出“建议跟进/可选阅读”并说明原因）
```

## 模板 4：偏学术/研究导向

```text
请以研究综述风格总结以下内容。
标题：{title}
正文：{content}

输出 Markdown，包含：
1. 核心问题定义
2. 方法或观点亮点（最多3条）
3. 局限性与开放问题（最多2条）
```

## 模板 5：极简速读

```text
请将以下文章压缩为“1分钟速读”。
标题：{title}
正文：{content}

输出 Markdown：
- 一句话摘要
- 关键点（最多2条）
- 原文是否推荐阅读（推荐/不推荐 + 1句话原因）
```

## 模板 6：开发者行动清单

```text
请阅读并总结以下文章，重点给出开发者可执行建议。
标题：{title}
正文：{content}

输出 Markdown，包含：
1. 核心结论
2. 可立即执行的行动项（2-4条）
3. 进一步学习关键词（3个以内）
```

## 使用方式

1. 从上面任选一个模板，复制为单行或保留换行均可。
2. 到 GitHub 仓库：`Settings → Secrets and variables → Actions → Variables`。
3. 新建或更新变量 `SUMMARY_PROMPT_TEMPLATE`。
4. 下次运行工作流时自动生效。
